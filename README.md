# Vetra

A free AI API for roleplayers. Built with ❤️ for the RP community.

## Overview

Vetra provides an OpenAI-compatible chat completions API tailored for roleplay:
- Character context persistence
- Conversation memory
- Easy persona switching
- Free tier access via OpenRouter

## Quick Start

```bash
# Clone
git clone https://github.com/CloudCompile/vetraaiapi.git
cd vetraaiapi

# Install dependencies
npm install

# Start dev server
npm run dev
```

## API Endpoints

- `POST /v1/chat/completions` - Chat completions (OpenAI-compatible)
- `GET /v1/models` - List available models
- `GET /health` - Health check

## Deployment

- **API**: Render (free tier)
- **Docs/Landing**: Vercel (free tier)
